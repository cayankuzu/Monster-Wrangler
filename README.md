# Monster Wrangler

Pygame ile yazılmış özgün Monster Wrangler oyununun tarayıcı sürümü.

- Masaüstü: Ok tuşları veya WASD, ışınlanmak için boşluk
- Mobil/tablet: Ekrandaki yön ve ışınlanma kontrolleri
- Özgün görseller, sesler, tur, skor, hedef ve can mekanikleri korunmuştur

`monster_wrangler.py` özgün Python kaynağıdır. Web sürümü `index.html`, `styles.css`
ve `game.js` dosyalarından çalışır.
